# netwrench-data

Справочные данные, которые NetWrench подтягивает файлом, без обновления
приложения. Здесь нет кода — только факты, которые приложение показывает
технику.

## router-defaults.json — заводской вход в роутер

Адрес веб-интерфейса и заводские учётные данные по вендору и модели. Нужны
там, где у NetWrench ещё нет модуля авторизации для этой железки: приложение
опознало роутер, но настроить его само не может — и тогда показывает, куда
зайти руками и чем.

Данные публичные: всё это напечатано в руководствах вендоров и на коробках.
NetWrench ничего не подбирает и не перебирает — пара подставляется в поля,
вход выполняет человек.

### Формат

```json
{
  "schema": 2,
  "version": 2,
  "updated": "2026-09-09",
  "entries": [ … ]
}
```

`version` — целое, растёт при каждом изменении. Приложение принимает файл
только со `version` больше текущего, поэтому её нужно поднимать в том же
коммите, что и правку записей.

Запись:

| Поле | Обязательно | Значение |
| --- | --- | --- |
| `id` | да | Стабильный идентификатор записи, уникальный по файлу |
| `vendor` | да | Имя вендора **ровно в том виде, в каком его выдаёт детектор** — см. ниже |
| `models` | нет | Канонические модели. Нет поля — запись описывает весь модельный ряд вендора |
| `addresses` | да | Адреса управления: IP и/или имя хоста, первым — основной |
| `access` | да | Службы управления и их порты — см. ниже |
| `auth` | да | Как устроен вход — см. ниже |
| `factoryReset` | нет | `holdSeconds` и/или `note`: как сбросить к заводским |
| `verified` | нет | `true`, если значение подтверждено на живой железке в ходе разработки |
| `note` | нет | Короткая заметка, объект `{ru, en}` |
| `source` | нет | Откуда взято |

### access

Список служб, каждая — `{type, port, enabled}`. `enabled` описывает состояние
**с завода**: `false` означает, что служба есть, но выключена, и стучаться в
неё бесполезно, пока её не включат через веб-интерфейс. Это избавляет техника
от диагностики отказа, которого нет.

Допустимые `type`: `http`, `https`, `ssh`, `telnet`, `api`, `api-tls`,
`winbox`. Веб-интерфейс (`http` или `https`) обязан присутствовать.

`ssh` и `telnet` с их портами напрямую кормят терминал NetWrench.

### auth

| Поле | Значение |
| --- | --- |
| `usernameField` | Есть ли в форме входа поле логина вообще. У Tenda, Mercusys, Xiaomi и новых Archer входят только паролем |
| `username` | Заводской логин. `null`, когда поля нет или логин придумывает пользователь |
| `usernameCreated` | Логин создаётся пользователем при первом входе |
| `password` | Заводской пароль. `""` — пустой, поле оставляют пустым. `null` — готового пароля нет |
| `passwordCreated` | Пароль создаётся пользователем при первом входе |
| `passwordOnLabel` | Пароль напечатан на наклейке устройства. Уживается с заводской парой: у розничного экземпляра работает `admin/admin`, у провайдерской прошивки того же вендора — наклейка |
| `wizardBlocks` | Пока не пройден мастер первичной настройки, управление недоступно (§ 9.2 правил проекта) |

Согласованность проверяет `validate.py`: придуманного пользователем значения
в базе быть не может, а пароль не может одновременно создаваться и быть
напечатанным на наклейке.

Отдельного поля «состояние» нет намеренно — оно выводится из `auth`, и
хранить его рядом значило бы завести второй источник правды, который рано
или поздно разойдётся с первым.

### Правило подбора

1. Точное совпадение по `vendor` **и** `models`.
2. Иначе — запись того же `vendor` без `models`.
3. Иначе — ничего; приложение показывает только то, что измерило само.

Записи с `models` идут в файле выше общей записи вендора, чтобы порядок
чтения совпадал с порядком подбора.

### Имена вендоров

`vendor` должен совпадать со строкой, которую выдаёт детектор NetWrench —
иначе запись не найдётся никогда. Источники строк в репозитории приложения:

* `discovery/…/RouterDetector.kt`, функция `detectVendor` — общий словарь брендов;
* `discovery/…/<vendor>/…FingerprintConfig.kt`, константа `VENDOR_FAMILY` — семейства с собственным детектором.

### Проверка перед публикацией

```sh
python3 validate.py
```

Ненулевой код возврата — файл публиковать нельзя.

## userscripts.json — каталог пользовательских скриптов

Скрипты, которые техник ставит во встроенный браузер NetWrench одним
нажатием. NetWrench выполняет их так же, как Violentmonkey или Tampermonkey —
на сайтах, которые назвал их собственный `@match`. Чаще всего это
веб-интерфейс роутера или внутренний инструмент оператора: они сделаны под
монитор и на телефоне неудобны, пока кто-нибудь их не поправит.

В файле лежат адреса, а не код. Приложение скачивает каталог, показывает, что
в нём есть, и забирает выбранный `.user.js` по адресу из записи — автор
продолжает публиковать скрипт там, где публиковал, и обновляет его там же, не
трогая этот репозиторий.

### Формат

```json
{
  "schema": 1,
  "version": 1,
  "updated": "2026-09-23",
  "entries": [
    {
      "id": "we-orders-fixes",
      "name": "WE — правки «Мої наряди»",
      "description": "Правки інтерфейсу списку нарядів CRM Westelecom.",
      "author": "zortald",
      "matches": ["https://crm.westele.com.ua/*"],
      "url": "https://gist.githubusercontent.com/…/we-orders-fixes.user.js"
    }
  ]
}
```

`version` — целое число, растёт с каждым изменением.

| Поле | Что это |
| --- | --- |
| `id` | постоянный идентификатор, `a-z0-9-`; не переиспользуется под другой скрипт |
| `name`, `description` | то, что каталог показывает до всякой загрузки |
| `author` | кто публикует, чтобы читатель понимал, чей код собирается запустить |
| `matches` | сайты, на которые скрипт претендует; копия его собственного `@match` |
| `url` | сам `.user.js`, **только https** |

Имя, версию и шаблоны приложение в итоге берёт из заголовка скачанного файла,
а не отсюда: иначе эти два источника разойдутся, а работает всё равно
заголовок.

`url` обязан быть https. Скачанное выполняется на странице, где у техника
открыта сессия, а телефон при этом часто сидит в чужой сети — нередко в той
самой, которую он и чинит, то есть ровно там, где подменить незашифрованную
загрузку проще всего.

### Проверка перед публикацией

```sh
python3 validate-userscripts.py
```

Ненулевой код возврата — файл публиковать нельзя.

## router-catalog.json — каталог моделей

Факты о железе по модели и ревизии: какие диапазоны Wi-Fi и какого поколения,
сколько портов и какой скорости, есть ли внешние антенны, снят ли с
производства. NetWrench показывает их в карточке «Мой роутер», когда сам
роутер без пароля этого не сообщает — а о портах до входа не сообщает ни один.

Файл не правится руками: его собирает `build_catalog.py` из `sources/`.

| Источник | Что это | Приоритет |
| --- | --- | --- |
| `sources/toh.json` | Снимок OpenWrt Table of Hardware, только нужные колонки и типы устройств | низший |
| `sources/manual.json` | Факты со страниц производителей, у каждой записи URL | выше |
| `sources/verified.json` | Увиденное на стенде | высший |

Поле более приоритетного источника перекрывает то же поле менее
приоритетного. В `origin` каждой записи сказано, откуда взят каждый факт, в
`sources` — ссылки. Факт, которого источник не сообщил, в запись не попадает:
неизвестно — не ноль.

```sh
python3 build_catalog.py --fetch-toh   # обновить снимок ToH и собрать
python3 build_catalog.py               # собрать из того, что лежит в sources/
python3 validate_catalog.py            # проверить перед публикацией
```

Запись:

| Поле | Смысл |
| --- | --- |
| `vendor`, `model`, `aliases` | Как модель называет детектор; `aliases` — маркетинговые имена и варианты (`hAP ac³`, `TL-WR841ND`) |
| `revisions` | Аппаратные ревизии (`v3`). Нет поля — ревизии не различаются |
| `type` | `router`, `ap`, `modem`, `extender` |
| `bands` | `{"2.4": "wifi4", "5": "wifi5"}`; диапазона нет в объекте — радио на нём нет. Нет поля — неизвестно |
| `ports` | Число портов по скорости: `100m`, `1g`, `2.5g`, `5g`, `10g`, `sfp`, `sfp+`. Все виды разом или ничего |
| `detachableAntennas` | Съёмные антенны (так считает ToH; 0 не значит «антенн нет») |
| `externalAntennas` | Внешние антенны, съёмные или нет, со страницы производителя |
| `status`, `availableAsOf` | `discontinued` / `available` и год, к которому относится отметка ToH |
| `fccId` | FCC ID, если известен. Даты гранта в каталоге нет: сайты FCC закрыты для автоматических запросов, обходить защиту мы не будем |
| `cpu`, `cpuCores`, `cpuMhz` | Процессор так, как его называет ToH, ядра и частота |
| `ramMb`, `flashMb` | Память; `flashMb` — только встроенная flash, слот карты или eMMC без размера не считается |
| `mimo` | Схема радиотрактов вида `2x2:2`, только если ToH даёт одну на все диапазоны |
| `openwrtSince`, `openwrtCurrent` | Первый и последний релиз OpenWrt для модели; `EOL`, когда сборки для неё прекращены |
| `powerSupply` | Как пишет ToH: `12 VDC, 1.0A via barrel` |
| `usb` | USB-порты под устройства (`1x 2.0, 1x 3.0`) или `none`; гнёзда только для питания не считаются |
| `vlan`, `outdoor` | `true` / `false` |
| `modem` | Встроенный модем: `VDSL2`, `LTE`… |
| `oemUrl`, `firmwareUrl` | Страница модели и страница стоковой прошивки у производителя, только https |

Одна модель с несколькими ревизиями — несколько записей. Приложение
показывает факт, только если все подходящие ревизии в нём согласны.

## intake/router-report.gs — «Сообщить о модели»

Веб-приложение Google Apps Script, привязанное к таблице проекта. Кнопка
«Сообщить о модели» в приложении отправляет один JSON-отчёт (производитель,
модель, прошивка, производитель по MAC, услышанные диапазоны, версия сборки),
когда в каталоге нет характеристик модели; скрипт проверяет его и дописывает
строку. Адрес, полный MAC, имя устройства и SSID не отправляются никогда. Адрес
веб-приложения публичный, поэтому скрипт отбрасывает неизвестные поля, слишком
длинные значения и больше 30 отчётов в минуту, а одну и ту же модель с прошивкой
записывает раз в шесть часов. Как развернуть — в начале файла; адрес передаётся
приложению gradle-свойством `netwrench.routerReportUrl`. После каждой новой версии Google снова просит
разрешение владельца и до этого отвечает всем 403: открыть адрес `/exec` в
браузере и разрешить.

## Лицензия и происхождение данных

`router-defaults.json` составлен вручную по руководствам вендоров и по
устройствам, проверенным в ходе разработки.

Чужие базы данных целиком не берутся (в ЕС на них действует sui generis
право, а NetWrench — платный продукт). Единственное исключение — базы,
открытые лицензией, которая это прямо разрешает, и только на её условиях.
Сейчас это одна база: OpenWrt Table of Hardware под CC BY-SA 4.0 в
`router-catalog.json`. Поэтому `router-catalog.json` и `sources/toh.json`
распространяются под **CC BY-SA 4.0** с атрибуцией OpenWrt (она записана в
самом файле). Отдельные факты — число портов, стандарт Wi-Fi — со страниц
производителей переносятся по одному, с ссылкой на страницу; тексты и
изображения не копируются.

Записи с `"verified": true` подтверждены на реальном оборудовании.
